Network Settings

Configure the network addresses for host and guest environments

Host IP Address
Please enter a valid IPv4 address
Primary network interface IP of the host machine
Run in Ubuntu WSL:
ip addr show | grep -A1 eth0 | grep inet | awk '{ print $2}'
Enter a comma-separated list of valid IPv4 addresses
Extra IP SANs
Sets the IP address(es) that will be added as IP Subject Alternative Names (IP SANs) in every generated SSL certificate.

Defaults to the Host IP shown above.
Change this value only when the certificate must also cover a different or extra IP (for example the public IP of an Azure, AWS or GCP instance).

The value is passed to generate-ssl.sh as EXTRA_IP_SANS_ENV.
If it differs from the Host IP, the “Use IP address” toggle above will automatically follow this field.
