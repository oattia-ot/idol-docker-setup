Overview

This dedicated view provides deep visibility into your IDOL Docker services, container health, metrics, logs, and infrastructure status. It aggregates data from the full monitoring stack (Prometheus, Grafana, Loki, cAdvisor, Dozzle, Yacht, Dockge, and the custom Config Monitor).

Key Capabilities

Real-time Health

Live CPU, memory, uptime and Docker status for every idol-* container.

Metrics & Dashboards

Grafana + Prometheus for historical trends and custom alerting.

Centralized Logging

Dozzle, Loki + Promtail for structured log search across all services.

Container Management

Yacht & Dockge for visual Docker Compose and stack management.
